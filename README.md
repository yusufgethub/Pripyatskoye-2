# Utilize this as a reference for how you should format your GitHub repository for shared map projects -
# you MUST do the following when creating a new GitHub project for it to work properly:

## You MUST make a backup of your map, this is purely for safety just in case something messes up,
## On top of that backup, you must make a secondary copy that you wish to push to MAIN on the GitHub.
## When importing the GitHub Project to your own Workbench, you must preserve the file structure or there will be issues.
## Importing to Workbench is simple, drag the original project file structure to your Workbench addons folder and Scan for Projects.
## Future updates to the GitHub must be through their own layers, nothing from the default layer file can be altered
## - an exception for this can be overriden entities, or imported assets, the file structure must be preserved when pushed.
